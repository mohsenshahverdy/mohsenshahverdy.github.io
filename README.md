# Mohsen Shahverdi — Portfolio

Personal portfolio for Mohsen Shahverdi, Senior AI Engineer. The site is a dependency-free static website designed for GitHub Pages.

It presents selected public work in agent infrastructure, production ML, cooperative perception, computer vision, and backend systems. Confidential employer work is described only at a high level.

## Local preview

Open `index.html` in a browser, or serve the directory with any static web server.

## Deployment

This repository is intended for GitHub Pages at `https://mohsenshahverdy.github.io`.
